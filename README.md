# OneBus-OA-Frontend
Frontend Development for OneBus

### Prerequisites

You'll need to have [Flutter](https://docs.flutter.dev/get-started/install) installed.

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/mmaliu97/OneBus-OA-Frontend.git
   ```
2. Install packages
   ```sh
   flutter pub get
   ```
3. Run the application
   ```sh
   flutter run
   ```

## Places of Interest Categories

The system categorizes points of interest (POIs) into four main service categories. Below is the complete mapping of available amenities:

### Category Mapping

| Amenity Type | Service Category |
|--------------|------------------|
| restaurant | Food Services |
| bar | Food Services |
| cafe | Food Services |
| pub | Food Services |
| marketplace | Commercial |
| place_of_worship | Community Services |
| social_centre | Community Services |
| library | Community Services |
| events_venue | Recreation |
| cinema | Recreation |
| theatre | Recreation |
| music_venue | Recreation |

### Category Descriptions

- **Food Services** – Establishments offering food and beverages including restaurants, bars, cafes, and pubs
- **Commercial** – Retail and trading venues such as marketplaces
- **Community Services** – Public facilities serving community needs including places of worship, social centers, and libraries
- **Recreation** – Entertainment and leisure venues like cinemas, theaters, event spaces, and music venues

*Additional amenity types will be added in future updates.*
